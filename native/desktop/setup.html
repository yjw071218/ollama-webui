사용할 서버 주소를 입력하세요.

서버를 켰을 때 표시되는 0.0.0.0.nip.io:0000 형식으로 입력하세요. IP만 입력하면(192.168.0.5:5173) 자동으로 바꿔 줍니다. 보안 서버는 https://를 붙이세요.

HTTP 연결은 대화·비밀번호·첨부 파일이 암호화되지 않습니다. 신뢰하는 서버에만 연결하세요. 가능하면 HTTPS를 사용하세요.
