# 1.0.9
- Windows 종료 시 이미 닫힌 주소 설정 창을 조회해 발생하는 Object has been destroyed 오류를 수정했습니다.
- 함께 배포하는 서버 1.0.4에는 새 기기의 초기 기본값이 계정 설정을 덮어쓰는 것을 막는 수정이 포함됩니다.
- 코드 패널은 창 너비의 최대 60%로 제한하고, 1280px 이하에서는 겹침 표시로 가운데 채팅이 눌리는 것을 방지합니다.
- 첫 설치 시 Google·카카오 키와 콘솔 등록을 단계별로 안내합니다. Google은 등록된 콜백이 있어야 직접 열기가 활성화됩니다.
- 카카오 앱용 경로를 사용하려면 실행 중인 웹서버도 업데이트 후 재시작해야 합니다. 실계정 로그인과 실기기 업데이트 설치는 별도 검증이 필요합니다.
