# 1.0.7
- 앱 안에서 바로 업데이트: 새 버전이 있으면 업데이트 창이 열리고, GitHub에 가지 않고 내려받아 설치합니다.
- 업데이트 창: 변경 사항, 다운로드 진행률(%)·속도·남은 시간, 취소, 이 버전 건너뛰기를 표시합니다.
- 내려받은 파일은 크기와 SHA-256을 확인한 뒤에만 설치합니다. Android는 같은 앱·같은 서명인지도 확인합니다.
- Windows 설치형은 자동으로 설치 후 다시 시작하고, "종료할 때 설치"를 고르면 앱을 닫을 때 설치합니다. 포터블은 파일을 새 버전으로 바꿔 다시 실행합니다.
- Android는 프로필 메뉴의 "업데이트 확인"으로 직접 확인할 수 있습니다. 설치 확인 화면은 Android 보안 정책상 한 번 눌러야 합니다.
