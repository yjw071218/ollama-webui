# 1.0.14
- 웹서버 1.0.10과 함께 사용하세요.
- Windows: F5·Ctrl+R로 새로고침, Ctrl+F5·Shift+F5·Ctrl+Shift+R로 캐시 무시하고 새로고침, F11로 전체 화면 (상황극 화면 안에서도 동작)
- Windows: 보기 메뉴에 새로고침(F5)과 캐시 무시하고 새로고침(Ctrl+F5) 표시

# 1.0.13
- 웹서버 1.0.9와 함께 사용하세요. 뒤로 가기, 알림을 눌러 대화로 이동, 내보내기 저장은 웹서버 1.0.9가 있어야 동작합니다.
- 뒤로 가기: 열린 창·메뉴·사이드바를 하나씩 닫고, 닫을 것이 없으면 앱을 백그라운드로 보냄 ('서버 변경' 창이 매번 뜨던 문제 수정)
- 대화 내보내기·백업·캔버스 문서 저장이 "외부 다운로드" 오류 없이 저장 위치 선택으로 이어지도록 수정
- 완료 알림 허용이 앱을 다시 켜도 유지되도록 수정 (서버별로 저장)
- 알림에 앱 아이콘 표시, 알림을 누르면 해당 대화로 이동
- 다크 모드 전환·화면 분할·폴더블 펼치기 때 페이지가 새로 고쳐지지 않도록 수정
- 실행할 때 흰 화면이 번쩍이지 않도록 수정, 앱 안의 확인 창이 화면 테마(밝게/어둡게)를 따름, 웹 앱의 '시스템' 테마가 휴대폰 다크 모드를 따름
- 가로 모드에서 내비게이션 바·카메라 노치가 화면을 가리지 않도록 좌우 여백 처리
- 서버에 연결할 수 없을 때 '다시 시도'·'서버 변경' 버튼이 있는 안내 화면 표시
- 서버 주소 화면: http:// 없이 입력해도 연결, 키보드 엔터로 연결, 앱 색상에 맞춘 입력칸·버튼
- 서버 연결을 요청마다 새로 맺지 않고 재사용해 화면 반응 속도 개선 (특히 HTTPS·모바일 데이터)
- Windows: 창 크기·위치·최대화 상태 기억, 최소화된 상태에서 다시 실행하면 창 복원
