# 1.0.8
- Google 로그인: 중간 페이지 없이 Google 계정 선택 창을 바로 엽니다. 앱이 로그인하는 동안만 127.0.0.1:47615에서 응답을 받습니다. Google 콘솔에 리디렉션 URI(http://127.0.0.1:47615/api/auth/native/google/callback)를 한 번 등록해야 하며, 등록 전이거나 서버가 1.0.3보다 오래됐으면 예전처럼 중간 페이지로 엽니다.
- 카카오 로그인: 서버가 앱 전용 경로를 모르는 옛 버전이면(HTTP 404) 오류 대신 앱 안 카카오 로그인으로 자동 전환합니다.
- 함께 배포한 웹서버 v1.0.3: 첫 설치 시 Google·카카오 키 발급과 콘솔 등록 방법을 이 서버 주소에 맞춰 단계별로 안내합니다. 오른쪽 코드 패널을 넓혀도 가운데 채팅이 일정 너비 아래로 줄지 않습니다.
