# 1.0.19
- 웹서버 1.0.21과 함께 사용하세요.

### Windows 앱
- 링크를 누르면 기본 브라우저 대신 앱 안의 브라우저 창에서 열림 (뒤로·앞으로·새로고침·주소창, "브라우저로" 버튼으로 기본 브라우저에서도 열 수 있음)
- 새 "실행" 작업 공간: 프로젝트 폴더를 고르면 실행할 수 있는 명령(npm 스크립트, Python, cargo, go, .bat 등)을 찾아 주고, 대화 영역 전체에서 실행·중지·재실행, 출력 확인, 입력 보내기, dev 서버 미리보기까지 가능. 처음 쓰는 폴더는 허용을 물어봄

### Android 앱
- 링크를 누르면 확인 창 없이 앱 위에 겹쳐 뜨는 인앱 탭으로 열림

### 웹서버 1.0.21 (서버를 업데이트하면 앱에도 적용)
- PC에서 대화에 마우스를 올리면 바로 아래에 버튼 캡슐이 항상 뜸 (오래된 메시지에서 안 뜨던 문제 수정). 클릭으로 하단 가운데에 뜨던 캡슐은 PC에서 제거, 모바일은 그대로
- 작성 중인 답변에는 캡슐이 뜨지 않음
- 경로·음성 입력·인용·프롬프트·태그가 입력창 맨 뒤가 아니라 커서 위치에 들어감

# 1.0.18
- 웹서버 1.0.13과 함께 사용하세요.

### Windows 앱
- 작업 표시줄에 고정한 아이콘과 실행 중인 창이 따로 뜨던 문제 수정
- 우클릭 메뉴 추가: 입력창에서는 실행 취소·잘라내기·복사·붙여넣기·모두 선택, 선택한 글자는 복사, 링크는 브라우저에서 열기·주소 복사, 이미지는 복사·저장, 틀린 단어는 추천 단어·사전에 추가
- 페이지가 비정상 종료되면 스스로 다시 불러옴. 1분 안에 세 번 반복되면 "서버 변경 / 다시 불러오기"를 물어봄
- 켜 둔 동안 6시간마다 업데이트 확인. "나중에"로 미룬 버전은 같은 실행 중에는 다시 띄우지 않고, 다운로드 중이거나 설치 준비가 끝난 상태에서는 갑자기 뜨지 않음

### Android 앱
- 화면(WebView)이 비정상 종료돼도 앱이 꺼지지 않고 페이지를 다시 엶. 1분 안에 세 번 반복되면 서버 주소 화면으로 돌아감
- 앱을 다시 열었을 때 마지막 확인에서 6시간이 지났으면 업데이트 확인
- 당겨서 새로고침: 화면 맨 위에서 아래로 끌어내린 뒤 손을 떼면 새로고침 (스크롤 중인 목록, 입력창, 대화 상자 안에서는 동작하지 않음)

### 웹서버 1.0.13 (서버를 업데이트하면 앱에도 적용)
- 다른 기기에서 바꾼 설정·폴더·프리셋·페르소나·프로필·문서·메모리가 새로고침 없이 바로 반영됨. 다른 기기에서 기본값으로 되돌린 설정도 반영
- 앱을 열면 계정과 동기화를 마친 뒤 화면이 나옴 (최대 8초). 동기화된 대화가 화면에 안 나와 다시 시작해야 하던 문제 수정
- 좁은 창에서 대화 내 검색창이 대화 내용에 가려지던 문제 수정
- 이미지 확대 보기 위에 실행 중 캡슐이 보이던 문제 수정
- 회색 기본 버튼으로 보이던 버튼들(페르소나 관리 등)의 디자인 수정
- 저장된 시스템 프롬프트와 "누구와 대화할까요" 페르소나 카드를 휴대폰에 맞게 다시 디자인
- CLI 모델이 명령으로 고친 파일도 수정 내역 카드로 표시

- 가로 모드에서 내비게이션 바·카메라 노치가 화면을 가리지 않도록 좌우 여백 처리

- 서버 주소 화면: http:// 없이 입력해도 연결, 키보드 엔터로 연결, 앱 색상에 맞춘 입력칸·버튼
- 서버 연결을 요청마다 새로 맺지 않고 재사용해 화면 반응 속도 개선 (특히 HTTPS·모바일 데이터)
- Windows: 창 크기·위치·최대화 상태 기억, 최소화된 상태에서 다시 실행하면 창 복원
