# 오피스 편집·AI 제작

## 대화에서 바로 제작

편집기를 열지 않고 대화에 **“위 내용을 PPT 8장으로 만들어줘”**, **“예산을 합계 수식이 있는 엑셀 파일로 만들어줘”**, **“이 내용을 Word 보고서로 작성해줘”**라고 요청할 수 있습니다. AI가 `office` 형식의 문서 블록을 응답하면 대화 안에 제목·분량·내용 미리보기와 다운로드 버튼이 표시됩니다. 버튼을 누르면 실제 파일을 생성하여 내려받습니다.

문서 구조는 답변에 포함되어 대화와 함께 저장됩니다. 다시 연 대화에서도 다운로드할 수 있으며, 수정은 “방금 발표자료를 5장으로 줄여줘”처럼 요청합니다. 모델에는 전체 수정본을 반환하도록 안내합니다. 구형 파일과 HWP는 기존 서버 변환 엔진을 사용하며, 실패 시 카드 안에 오류와 재시도 안내를 표시합니다. 실제 모델의 형식 준수 여부에 따라 재요청이 필요할 수 있습니다.

대화 카드의 PPTX·XLSX·DOCX 다운로드 및 재열기를 브라우저에서 검증했습니다. 모델의 문서 응답 자체는 이 검사에서 고정된 입력을 사용했습니다.

채팅 입력창의 **+ → 오피스 · AI 제작**에서 엽니다. Canvas의 **문서 제작** 버튼으로 답변 내용을 가져올 수도 있습니다. 채팅에서 선택한 모델을 그대로 사용합니다.

## 지원 범위

| 종류 | 열기 | 저장 | 편집 기능 |
|---|---|---|---|
| 발표자료 | PPT, PPTX, ODP | PPTX, PPT, ODP, PDF | 새 슬라이드 제작·추가·삭제, 레이아웃·테마·본문·발표자 노트 변경, 기존 파일 텍스트 수정 |
| Word | DOC, DOCX, ODT, RTF, TXT | DOCX, DOC, ODT, RTF, TXT, PDF | 새 문서 제작, 기존 본문·머리말·꼬리말·각주 텍스트 수정 |
| Excel | XLS, XLSX, XLSB, ODS, CSV, TSV | XLSX, XLS, ODS, CSV, TSV, PDF | 셀 값·수식 편집, 여러 시트 열기·추가, 행·열 페이지 이동 |
| 한글 | HWP, HWPX | HWPX, HWP | 새 문서 제작, 기존 텍스트 수정 |

**오피스 프로그램 자체를 브라우저에 이식한 것은 아닙니다.** 기존 슬라이드/문서의 도형을 마우스로 배치하는 편집, VBA 실행, Excel 차트·피벗의 완전한 보존, Access·Project·Visio 파일 편집은 이 구현의 지원 범위에 포함하지 않습니다. 기존 PPTX/DOCX/HWPX의 텍스트 외 구성 파일은 유지하지만, 형식 변환과 텍스트 길이 변경으로 원본 배치가 달라질 수 있습니다. 중요한 원본은 별도로 보관하고 다운로드한 사본을 확인하세요.

## AI가 직접 만드는 방법

1. 발표자료, Word, Excel, 한글 중 제작할 종류를 선택합니다.
2. **AI에게 제작 요청**에 목적·독자·내용·분량을 입력합니다.
3. **AI 디자인·제작**을 누릅니다. 작업 중에는 생성 취소가 가능합니다.
4. 슬라이드 디자인 또는 문서/표 제안을 확인하고 **편집기에 적용**합니다.
5. 필요한 부분을 수정한 뒤 원하는 형식으로 저장합니다.

발표자료에는 표지·본문·비교·카드·차트·타임라인의 6가지 레이아웃과 midnight·paper·ocean의 3가지 테마를 제공합니다. AI가 각 슬라이드의 레이아웃·내용·테마·발표자 노트를 구성합니다. 미리보기와 PPTX는 동일한 위치·크기·색상 데이터를 사용하고, 내보낸 글자와 도형도 편집할 수 있습니다. 차트는 편집 가능한 도형으로 제작되며 Excel에 연결된 네이티브 차트 개체는 아닙니다.

예시 요청:

> 아래 내용을 임원 보고용 8장 발표자료로 구성해 줘. 남색 테마를 사용하고, 문제·해결책·추진 일정·기대 효과를 구분해 줘. 제공하지 않은 수치는 만들지 마.

> 주간 프로젝트 관리용 Excel을 만들어 줘. 업무·담당자·기한·진행률 시트와 예산 합계 수식을 포함해 줘.

AI 출력은 JSON 문서 구조로 검사한 뒤 적용합니다. 잘못된 응답은 오류로 표시하며 현재 작업을 덮어쓰지 않습니다. 제안을 적용하기 전 작업은 로컬 초안에 저장합니다. 초안은 브라우저·계정별로 저장되며 기기 간 동기화 대상은 아닙니다.

## 변환 엔진

PPT/DOC/ODF 변환과 PDF 출력, XLS·ODS 수식 보존에는 **서버의 LibreOffice**를 사용합니다. Windows에서는 다음 명령으로 다운로드 해시를 확인한 후 프로젝트 전용 실행 파일을 준비합니다.

```powershell
npm run office:setup
```

기본 위치는 `native/artifacts/office-runtime/program/soffice.exe`입니다. MSI 관리 설치 모드로 파일만 추출하므로 기본 오피스 앱이나 파일 연결을 변경하지 않습니다. 서버를 다른 PC에 배포하면 그 PC에서도 엔진을 준비해야 합니다. Windows의 일반 LibreOffice 설치 경로, Linux의 `/usr/bin/libreoffice`, macOS의 기본 앱 경로도 검색합니다. 별도 위치는 **WEBUI_LIBREOFFICE** 환경 변수로 지정합니다.

공식 [명령행 변환 필터](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html)를 사용합니다. 요청마다 분리된 임시 프로필을 만들어 기존 LibreOffice 창과 충돌하지 않도록 합니다. 변환은 한 번에 하나씩 실행하며, 50 MB 크기 제한과 90초 실행 제한을 적용합니다.

HWP↔HWPX는 한/글이 설치된 Windows 서버의 자동화를 사용합니다. LibreOffice만으로 최신 HWP 저장을 지원한다고 안내하지 않습니다.

## Excel 주의 사항

- `=`로 시작하는 셀은 수식입니다. 편집 화면은 수식을 실행하지 않습니다.
- XLSX에는 문서를 열 때 전체 계산을 수행하도록 설정합니다.
- XLS·ODS는 XLSX를 중간 형식으로 사용하여 LibreOffice에서 계산하고 저장합니다. 브라우저 라이브러리만으로 저장할 때 수식이 누락되는 문제를 피합니다.
- CSV·TSV는 첫 시트의 평면 데이터입니다. 서식·시트 구조·계산 모델을 유지하려면 XLSX를 사용하세요.
- 한 번에 30행·12열을 편집하며, 페이지 버튼 또는 시작 행 번호로 다른 영역에 접근합니다.

## 다이어그램 이동

Mermaid의 SVG는 원본 코드가 바뀔 때만 교체합니다. 마우스·터치 이동은 프레임당 한 번으로 합치고, 이동을 지연시키던 CSS 전환을 제거했습니다. 초기 등장 애니메이션은 유지합니다. 가로 이동은 커스텀 제스처로 처리하여 브라우저의 가로 스크롤과 중복되지 않도록 했고, 기본 배율에서는 세로 페이지 스크롤을 유지합니다.

## 검사

```powershell
npm run test:office:browser
npm run build
```

오피스 브라우저 검사는 DOCX 편집, 표 값·수식 보존, 6가지 PPTX 디자인, 구형 PPT 왕복 변환, DOC/ODT/ODP 변환, PDF 출력과 실제 마우스·터치 이벤트를 검사합니다. AI UI 검사는 재현 가능한 모의 모델 응답을 사용하므로 특정 실제 모델의 결과 품질을 보증하지 않습니다.

### 2026-10-12 재검증

- 웹 프로덕션 빌드 통과. 번들 크기 및 XLSX 중복 정적·동적 import 경고는 남아 있습니다.
- 오피스 브라우저 통합 검사 통과: 구형 PPT·HWP 왕복, DOC·ODT·ODP 왕복, Word·Excel·PowerPoint PDF 출력.
- XLS·ODS 수식 검사는 여러 셀 범위 `SUM(B2:B3)`를 사용합니다. LibreOffice가 단일 셀 범위를 동등한 수식으로 정리하는 동작을 오류로 판정하지 않도록 보완했습니다.
- 마우스·터치·핀치 이동 중 SVG 교체 없음, AI 제안 미리보기·적용 및 데스크톱·모바일 화면 폭 검사 통과.
- 저장소 보안 검사 및 동기화 109개 검사 통과.
- AI는 모의 응답으로 UI 연결을 검증했습니다. 모바일은 브라우저 화면 에뮬레이션이며 실기기 검증은 아닙니다. 이번 재검증에서 네이티브 설치 파일을 다시 패키징하지 않았습니다.
