## 1. 준비물

| 필요한 것 | 왜 필요한가요 | 받는 곳 |
|---|---|---|
| Ollama | 내 PC에서 AI 모델을 돌려요. 없으면 첫 실행에서 설치를 도와줘요(Windows). | https://ollama.com |
| (선택) Claude Pro/Max | Claude Code를 쓸 때 | https://claude.ai |
| (선택) ChatGPT Plus 이상 | Codex를 쓸 때 | https://chatgpt.com |

## 2. 설치와 첫 실행 (반자동)

1. [Releases](https://github.com/yjw071218/ollama-webui/releases)에서 내 OS용 파일을 받아요. Windows는 설치 파일을 실행하면 돼요.
2. 설치가 끝나면 Ollama WebUI가 실행되고, 검은 실행 창이 차례로 물어봐요. 대부분 Enter나 `y`만 누르면 돼요.

| 단계 | 하는 일 | 자동으로 처리되는 것 |
|---|---|---|
| 설정 가져오기 | 바탕 화면·다운로드에 `ollama-webui-setup.json`이 있으면 가져올지 물어요. | 토큰·소셜 키·API 키를 그대로 넣어요 |
| [1/5] 접속 토큰 | 다른 기기에서 들어올 때 쓰는 비밀번호예요. | Enter만 누르면 만들어 줘요 |
| [2/5] 소셜 로그인 | Google·Kakao 키를 붙여 넣어요. | 접속 주소(nip.io)를 정하고, 콘솔을 열고, 등록할 값을 그대로 보여 줘요 |
| [3/5] 코딩 CLI | 구독 중인 것만 `y` | 설치·로그인, 이미 로그인된 건 건너뜀 |
| [4/5] Ollama | 모델이 없으면 받을지 물어요. | Ollama가 없으면 winget 설치, 꺼져 있으면 켜기 |
| [5/5] 음성·ComfyUI·FFmpeg | 음성 엔진과 ComfyUI를 설치할지 물어요. | FFmpeg는 설치 파일에 들어 있어요. 음성(약 7GB)·ComfyUI(약 6GB)는 받아서 설치해요 |

### ComfyUI 사양

ComfyUI(그림·영상)는 아래 사양을 **모두** 넘는 PC에만 설치돼요.

| 항목 | 최소 | 이 정도면 쾌적 |
|---|---|---|
| NVIDIA VRAM | 6 GB | 12 GB 이상 |
| RAM | 16 GB | 32 GB 이상 |
| RAM + 가상 메모리(페이지 파일) | 32 GB | — |

- 최소와 쾌적 사이면 설치는 되지만 "느릴 수 있다"는 경고가 실행 창과 스튜디오 화면에 떠요. VRAM 8GB 미만이면 `--lowvram`으로 켜요.
- 가상 메모리만 모자라면: 설정 → 시스템 → 정보 → 고급 시스템 설정 → 성능 설정 → 고급 → 가상 메모리에서 늘린 뒤 `node server/install-engines.mjs`를 다시 실행하세요.
- ComfyUI 본체만 설치돼요. 그림 모델(체크포인트)은 `engines\comfyui\ComfyUI\models\checkpoints`에 따로 넣어야 해요.
- 기본 목소리 모델 **ai-voice**가 설치 파일에 들어 있어요. 음성 엔진을 설치하면 자동으로 연결돼요.
- **참조 음성은 직접 정해야 해요.** 목소리는 대부분 참조 음성을 따라가요. 3~10초짜리 깨끗한 음성 파일을 PC에 두고 설정 → 음성의 "레퍼런스 오디오 경로"에 그 경로를, 그 아래 칸에 파일에서 말하는 문장을 적으세요. 비워 두고 읽어주기를 누르면 이 안내가 떠요.
- 음성 인식(STT)은 음성 엔진 안의 Whisper를 써서 따로 설치할 게 없어요. 마이크를 처음 쓸 때 자동으로 켜지고, 모델(약 500MB)을 한 번 받아요.

3. Windows 방화벽 권한 창이 뜨면 **예**를 눌러 주세요.
4. 브라우저가 자동으로 열려요. 이후에는 실행할 때마다 Ollama도 함께 켜져요.

다시 설정하려면 앱 폴더(`%LOCALAPPDATA%\Programs\Ollama WebUI\app` 등)에서 아래를 실행하세요.

```
..\runtime\node.exe server\first-run.mjs --reconfigure
```

## 3. 쓰던 PC 설정 그대로 옮기기

새 PC에서 기존 PC와 똑같이 동작하게 하려면 설정 파일 하나만 옮기면 돼요.

1. **쓰던 PC**의 앱(또는 프로젝트) 폴더에서:
   ```
   node server/setup-bundle.mjs export
   ```
   바탕 화면에 `ollama-webui-setup.json`이 생겨요.
2. 이 파일을 **새 PC**의 바탕 화면이나 다운로드 폴더에 둬요.
3. 새 PC에서 설치하면 첫 실행이 파일을 찾아서 가져올지 물어요. `y`를 누르면 끝이에요.

옮겨지는 것: 접속 토큰, Google·Kakao 키, 웹 검색 API 키, CLI 설정(`CLI_*`), Ollama·ComfyUI 설정, 백업 설정.
옮기지 않는 것: PC마다 다른 경로(FFmpeg, 엔진 폴더, 인증서)와 접속 주소(새 PC에서 다시 정해요).

> 이 파일에는 토큰과 API 키가 들어 있어요. 옮긴 뒤에는 꼭 지우세요.

대화 기록은 계정에 저장되므로, 같은 서버에 로그인하면 그대로 보여요. 서버 자체를 옮기려면 `server/data/webui.db`를 앱을 끈 상태에서 복사하세요.

## 4. 소셜 로그인 (Google · Kakao)

Google·Kakao는 콘솔에 등록된 주소에서만 로그인을 허락해요. 이 부분만은 사람이 콘솔에서 한 번 등록해야 해요. 첫 실행이 등록할 값을 그대로 출력해 주니 복사해서 붙이면 돼요.

**Google**
1. [Google Cloud 콘솔 → 사용자 인증 정보](https://console.cloud.google.com/apis/credentials)에서 **OAuth 클라이언트 ID → 웹 애플리케이션**을 만들어요.
2. **승인된 JavaScript 원본**에 첫 실행이 보여 준 주소(예: `http://192.168.0.10.nip.io:5173`)와 `http://localhost:5173`을 넣어요.
3. 만들어진 클라이언트 ID를 첫 실행에 붙여 넣어요.

**Kakao**
1. [Kakao Developers → 내 애플리케이션](https://developers.kakao.com/console/app)에서 앱을 만들어요.
2. **플랫폼 → Web**에 위 주소를, **카카오 로그인 → Redirect URI**에 `주소/kakao/callback`을 넣고 카카오 로그인을 켜요.
3. **앱 키 → REST API 키**를 붙여 넣어요. Client Secret을 켰다면 그것도 넣어요.

주소가 바뀌면(공유기 교체 등) 콘솔에도 새 주소를 추가해야 해요. `.env`의 `PUBLIC_ORIGIN`이 지금 쓰는 주소예요.

## 5. 앱 안 가이드

처음 접속하면 가이드 카드가 떠요.

- **자동 점검:** Ollama 연결, 대화 모델, 임베딩 모델, CLI 로그인 상태를 확인하고 빠진 모델은 버튼 한 번으로 받아요.
- **건너뛰기:** 언제든 "건너뛰기"나 Esc로 닫을 수 있어요.
- **다시 보기:** 설정 → 일반 → **초보자 가이드 다시 보기**.

## 6. 기본 사용법

- **모델 고르기:** 화면 위쪽 모델 선택에서 골라요. CLI 모델도 같은 목록에 있어요.
- **파일 첨부:** 대화 화면 어디에나 끌어다 놓으면 돼요. 긴 파일은 그 대화에서만 자동으로 참고하고, 파일 경로도 AI에게 전달돼요.
- **폴더:** 끌어다 놓으면 입력창에 폴더 경로가 들어가요.
- **명령:** 입력창에 `/`를 치면 명령 목록이, `Ctrl+K`로 명령 팔레트가 열려요.
- **웹 검색·도구:** 입력창의 `+` 버튼에서 켜고 꺼요.
- **스튜디오:** 왼쪽 사이드바에서 그림·영상을 만들어요.
- **상황극:** 캐릭터 대화용 탭이에요. 로그인하면 기기 사이에 동기화돼요.
- **공용 문서:** 설정 → 지식에 올린 문서는 모든 대화가 참고해요.

## 7. 코딩 CLI 쓰기

- Claude Code·Codex·Antigravity 모델을 고르면 PC에 로그인된 구독으로 답해요.
- 우측 상단 배지가 한도와 초기화까지 남은 시간을 보여 줘요. 누르면 한도별로 자세히 나와요.
- 모델 목록은 각 CLI에서 직접 받아와요. 새 PC에서 목록이 적게 보이면 CLI에 로그인한 뒤 30초쯤 지나 새로고침하세요.

## 8. 휴대폰·외부에서 접속

- **같은 와이파이:** 실행 창에 나온 `http://192.168.x.x.nip.io:5173` 주소를 휴대폰에서 열고 접속 토큰을 입력해요.
- **항상 같은 주소로:** PC에서도 이 주소로 접속하세요. 주소가 다르면 로그인과 저장된 데이터가 따로 놀아요.
- **집 밖:** 공유기에서 포트 5173을 PC로 포트포워딩하세요. 토큰은 길고 복잡하게 쓰는 걸 권해요.

## 9. 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| "Ollama에 연결할 수 없어요" | Ollama가 설치됐는지 확인하고 앱을 다시 실행하세요. 실행할 때 자동으로 켜져요. |
| 모델 목록이 비어 있음 | 가이드의 "받기" 버튼이나 `ollama pull qwen3:8b` |
| 휴대폰에서 안 열림 | 같은 와이파이인지, 방화벽 허용을 눌렀는지 확인하세요. |
| Google 로그인 버튼이 안 됨 | 콘솔의 "승인된 JavaScript 원본"에 지금 주소가 정확히 들어갔는지 확인하세요. |
| Kakao 로그인에서 KOE006 | Redirect URI가 `주소/kakao/callback`과 글자 하나까지 같은지 확인하세요. |
| CLI가 "로그인 필요" | `--reconfigure`로 다시 로그인하거나 터미널에서 `claude` / `codex login` / `agy` 실행 |
| 설치 중 "사용 중인 파일" 창 | 실행 중인 Ollama WebUI 창을 닫고 다시 설치하세요. |
