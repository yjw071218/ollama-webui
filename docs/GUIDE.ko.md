# Ollama WebUI 초보자 가이드

처음 쓰는 분을 위한 안내예요. 순서대로 따라 하면 10분 안에 첫 대화를 할 수 있어요.

## 1. 준비물

| 필요한 것 | 왜 필요한가요 | 받는 곳 |
|---|---|---|
| Ollama | 내 PC에서 AI 모델을 돌려요 | https://ollama.com |
| (선택) Claude Pro/Max | Claude Code를 쓸 때 | https://claude.ai |
| (선택) ChatGPT Plus 이상 | Codex를 쓸 때 | https://chatgpt.com |
| (선택) Google AI Pro/Ultra | Antigravity(agy)를 쓸 때 | https://antigravity.google |

구독이 없어도 Ollama 모델만으로 충분히 쓸 수 있어요.

## 2. 설치와 첫 실행 (반자동)

1. [Releases](https://github.com/yjw071218/ollama-webui/releases)에서 내 OS용 파일을 받아 압축을 풀어요.
2. `OllamaWebUI.cmd`(Windows) 또는 `ollama-webui.sh`(Linux·macOS)를 실행해요.
3. 실행 창이 세 가지를 물어봐요.
   - **[1/3] 접속 토큰:** 휴대폰 등 다른 기기에서 들어올 때 쓰는 비밀번호예요. Enter만 누르면 자동으로 만들어 줘요. 꼭 적어 두세요.
   - **[2/3] 코딩 CLI:** 이미 설치·로그인된 CLI는 자동으로 감지해서 묻지 않아요. 나머지는 "구독 중인가요?"에 `y`를 누르면 설치하고 로그인 창을 띄워 줘요. 구독이 없으면 Enter로 건너뛰세요.
   - **[3/3] Ollama 점검:** 모델이 없으면 추천 모델(`qwen3:8b`, `qwen3-embedding:0.6b`)을 받을지 물어봐요.
4. Windows 방화벽 권한 창이 뜨면 **예**를 눌러 주세요.
5. 브라우저가 자동으로 열려요.

다시 설정하려면 앱 폴더에서 `node server/first-run.mjs --reconfigure`를 실행하세요.

## 3. 앱 안 가이드

처음 접속하면 가이드 카드가 떠요.

- **자동 점검:** Ollama 연결, 대화 모델, 임베딩 모델, CLI 로그인 상태를 확인하고 빠진 모델은 버튼 한 번으로 받아요.
- **건너뛰기:** 언제든 "건너뛰기"나 Esc로 닫을 수 있어요.
- **다시 보기:** 설정 → 일반 → **초보자 가이드 다시 보기**.

## 4. 기본 사용법

- **모델 고르기:** 화면 위쪽 모델 선택에서 골라요. CLI 모델도 같은 목록에 있어요.
- **파일 첨부:** 대화 화면 어디에나 끌어다 놓으면 돼요. 긴 파일은 그 대화에서만 자동으로 참고해요.
- **명령:** 입력창에 `/`를 치면 명령 목록이 나와요.
- **스튜디오:** 왼쪽 사이드바에서 그림·영상을 만들어요.
- **사용량:** 우측 상단 배지를 누르면 CLI 한도를 볼 수 있어요.

## 5. 휴대폰·외부에서 접속

- 같은 와이파이: 실행 창에 나온 `http://192.168.x.x:5173` 주소를 휴대폰에서 열고 접속 토큰을 입력해요.
- 집 밖: 공유기에서 포트 5173을 PC로 포트포워딩하세요. 토큰은 길고 복잡하게 쓰는 걸 권해요.

## 6. 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| "Ollama에 연결할 수 없어요" | Ollama 앱을 실행했는지 확인하세요. |
| 모델 목록이 비어 있음 | 가이드의 "받기" 버튼이나 `ollama pull qwen3:8b` |
| 휴대폰에서 안 열림 | 같은 와이파이인지, 방화벽 허용을 눌렀는지 확인하세요. |
| CLI가 "로그인 필요" | `--reconfigure`로 다시 로그인하거나 터미널에서 `claude` / `codex login` / `agy` 실행 |
