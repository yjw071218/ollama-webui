# 저장소·문서 편집 변경 사항

> 후속 구현으로 구형 PPT 왕복 변환, Word·Excel·ODF·PDF 변환과 AI 제작이 추가되었습니다. 현재 지원 범위와 검사 방법은 [오피스 편집·AI 제작](office-suite.ko.md)을 참고하세요. 아래 PPT 시간 초과 기록은 LibreOffice 전환 전의 검사 이력입니다.

## 사용 방법

채팅 입력창의 `+` 메뉴에서 **문서·발표자료 만들기**를 선택합니다. Canvas의 **문서 제작**으로 답변 내용을 편집기에 가져올 수도 있습니다.

- PPTX: 슬라이드 제목·본문 입력, 슬라이드 추가·삭제, 파일 생성 및 기존 텍스트 편집.
- HWPX: 본문 작성, 파일 생성 및 기존 텍스트 편집.
- HWP: Windows 서버에 설치된 한/글을 통해 HWPX로 가져오고 HWP로 내보내기.
- PPT: 한쇼 또는 PowerPoint 자동화를 통한 변환 경로가 있으나, 현재 PC의 한쇼 호출은 시간 초과로 실제 왕복 검증에 실패했습니다. PPTX를 사용하면 브라우저에서 제작·편집할 수 있습니다.

기존 PPTX/HWPX는 압축 내부의 텍스트 XML을 수정하고 다른 구성 파일을 유지합니다. 원본 프로그램과 같은 시각 편집기는 아니며, 글이 길어지면 배치가 달라질 수 있습니다. 문서 초안은 현재 브라우저에 저장되며 기기 간 동기화 대상이 아닙니다.

## 암호화와 복원

서버 DB의 records, record_history, history_blobs, record_quarantine, shares 본문을 AES-256-GCM으로 암호화합니다. 검색 인덱스에는 키 기반 HMAC으로 변환한 검색 조각을 저장합니다. 계정 메타데이터, 첨부 파일, 브라우저 IndexedDB와 문서 초안까지 암호화하는 기능은 아닙니다.

**DB 복원에는 동일한 암호화 키가 필요합니다.** 기본 키 파일은 서버 데이터 디렉터리의 `storage.key`입니다. Windows에서는 서버를 실행한 사용자 계정의 DPAPI로 보호되므로 파일 복사만으로 다른 PC·계정에서 복원이 보장되지 않습니다. 외부 키를 사용하는 배포는 `WEBUI_DB_KEY`에 Base64 형식의 32바이트 키를 지정하거나 `WEBUI_DB_KEY_FILE`로 키 파일 위치를 지정할 수 있습니다. 이미 암호화된 DB에 임의의 새 키를 지정하면 시작이 거부됩니다. DB 백업과 기존 키를 함께 보관해야 합니다.

기존 평문 DB는 최초 초기화에서 마이그레이션하고 WAL 정리와 VACUUM을 실행합니다. 이전에 따로 만든 평문 백업 파일은 변경하지 않습니다.

## 삭제 기록과 검색

삭제 기록은 기본 30일 보관 후 활성 기기의 동기화 확인 지점을 기준으로 정리합니다. 확인 기록이 없는 등록 기기가 있으면 정리를 보류합니다. 180일 이상 활동하지 않은 기기는 확인 지점 계산에서 제외하고, 정리 시점보다 오래된 커서의 업로드는 차단합니다. 재동기화 시 서버에 없는 로컬 자료는 복구 사본으로 보관하여 화면에서 JSON으로 내려받을 수 있습니다.

검색 시작 시점의 동기화 정보를 사용하므로 검색 도중 변경된 대화는 로컬 검색으로 확인합니다. 계정 전환 시 이전 계정의 검색 결과는 적용하지 않습니다.

## 검증 기록

2026-10-11 재검증:

- 웹 프로덕션 빌드 통과. 큰 번들 경고는 남아 있습니다.
- 저장소 암호화·검색·이력·안전한 GC 검사 통과.
- 동기화 검사 109개 통과.
- 브라우저 PPTX/HWPX 생성·수정·재열기 및 300행 가상화 검사 통과.
- 실제 한/글을 사용한 HWPX → HWP → HWPX 본문 보존 검사 통과.
- Windows 설치형·포터블 패키지 생성 성공.
- 구형 PPT 자동화 검사는 시간 초과 후 파일 잠금(EBUSY) 발생. 정리 오류가 원래 변환 오류를 덮지 않도록 수정했습니다. 모바일 실기기 동작은 이번 검사에 포함하지 않았습니다.

실행 명령:

```powershell
node scripts/storage-security.test.mjs
node scripts/syncengine.test.mjs
node scripts/office-virtual.browser.test.mjs
# 구형 PPT 자동화를 반드시 검사하려면:
node scripts/office-virtual.browser.test.mjs --ppt
npm run build
```
