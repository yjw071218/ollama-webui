# 답변 이어가기와 시각 자료

중단된 답변에는 **이어서 생성**을 제공합니다. 기존 메시지와 도구 결과를 보존한 채 실제 파일 상태부터 확인하도록 요청합니다. CLI가 재개 가능한 세션을 알려준 경우 시간 초과 외 오류에서도 같은 세션을 이어갑니다. 세션이 없으면 기존 대화로 이어가며 같은 세션을 복원했다고 표시하지 않습니다. 이미 실행이 시작된 요청은 네트워크 오류라고 해서 자동 재전송하지 않습니다. 사용량 제한 자체가 해제되는 기능은 아닙니다.

`infographic`은 생성 도중 JSON이 미완성이어도 일반 코드 카드로 바뀌지 않습니다. 대소문자, 통계 별칭, `sections`, JSON 끝 쉼표를 처리하고 원본 확인을 제공합니다. 기존 stats, steps, timeline, compare, progress, cards, proscons, funnel, callout 외 다음을 지원합니다.

- `media`: `items`의 title, text, image(실제 HTTP/HTTPS 이미지 주소), alt, sources. 이미지 없이 icon도 사용 가능합니다.
- `chart`: `chart`에 기존 chart 스키마를 넣습니다.
- `panel`: title, blocks, note로 통계와 비율·차트를 함께 묶습니다.
- 모든 블록에 `sources: [{title, url}]`과 note를 넣을 수 있습니다. 전후 변화는 stats.value에 문자열로 표시합니다.

숫자·이미지 주소·출처는 실제 자료에서 가져와야 합니다. 새 형식 안내는 모델 프롬프트에도 포함됩니다. 일반 Markdown 출처 링크와 번호 인용은 작은 아이콘 칩으로 표시하며 문서 인용은 기존 원문 확인 기능을 유지합니다. 표의 `<br>`, `<br/>`, `<BR />`는 줄바꿈하고 코드 안의 문자는 그대로 유지합니다. 임의 HTML을 실행하지 않습니다.

논문 요청 시 `/api/research/papers`가 Crossref 서지정보를 조회합니다. DOI, 제목, 저자와 연도를 원본 메타데이터로 전달하며 조회 실패를 숨기지 않습니다. DOI 등록 확인은 내용의 진실성·질의 관련성·인과관계 검증과 다릅니다. 본문이 없으면 결론을 검증했다고 주장하지 않도록 안내합니다. Crossref에 없는 자료도 있으므로 검색 실패는 논문이 존재하지 않는다는 증거가 아닙니다. 모델의 허위 생성 가능성을 완전히 없애는 보장은 아닙니다.

PPT는 11개 편집 가능한 레이아웃, 6개 테마, 선택적 강조색과 섹션 라벨을 지원합니다. 발표 대상에 맞는 이야기 구조와 다양한 구도를 사용하고 긴 설명은 발표자 노트로 이동하도록 안내합니다. 다운로드 카드에는 실제 첫 슬라이드 미리보기, 파일 종류 아이콘, 다운로드 진행 상태가 표시됩니다.

검증: `npm run test:presentation`, `node scripts/cliextras.test.mjs`, `node scripts/office-suite.browser.test.mjs`, `npm run build`. 브라우저 검사는 Windows Chromium이 필요하며 외부 모델 응답은 모의 데이터로 검증합니다.
